22 · App UI

App surfaces that hold the brand.

DTPR App UI — app icon, favicon, splash screen, empty state, error state, dark variant. The brand at the surfaces the user actually touches.

APP UIFAVICONDARK MODE

App icon

Rounded square (iOS / macOS 22% radius; Android 24dp adaptive). Navy surface, inverse mark. No wordmark — the icon must read as the mark at 16×16.

App icon · 1024×1024 master · navy surface · inverse mark

Favicon

Same mark, simplified stroke weight at the smallest sizes (16, 32 px). The internal cutout square becomes invisible at 16 px; the mark reads as a navy hexagon with a small white circle. At 64 px and up, all three elements read.

Splash screen

White surface, mark at center, italic display tagline beneath, navy spinner below. No chartreuse — splash is a state of "loading," not "live."

Empty state

When a section has no data: white surface, soft navy illustration, short headline, one-sentence body, primary CTA. No chartreuse — empty is not live.

Dark variant

Where the user opts into dark mode (or the system does), the substrate shifts to deep navy (#070D24), text becomes paper, the chartreuse pulse stays on the live indicator. The mark and CTA tokens are identical; only the substrate and text colors change.

Accessibility

  • WCAG 2.2 AA floor. Navy-on-paper passes for body text (≥7:1). White-on-chartreuse fails for body text but is allowed for the CTA label only because the chartreuse surface is reserved for primary action.
  • Tap targets ≥44×44. Every interactive element in any app UI surface hits 44px minimum on both axes.
  • Focus visible. Custom focus ring (2px chartreuse, 2px offset) on every focusable element.
  • Motion reduced. Every animated transition respects prefers-reduced-motion: reduce. The splash spinner, the chartreuse pulse, the screen-swap — all stop.
