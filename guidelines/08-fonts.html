The Source family lockup

Three families. Each has one job. The lockup is the family's coherence — Source Sans 3 owns display and body and UI; Source Serif 4 Italic owns the editorial moment; Source Code Pro owns code and taxonomy identifiers only.

The three families

All three families ship from Adobe and are licensed under the SIL Open Font License. Same x-height, same metrics, designed to pair.

Display + Body + UI · Source Sans 3
Standardize trust for digital places and routines.
The Technical Evaluator has already arrived. Recipe B's specific contribution is technical credibility — the page should feel like a tool, not a brochure. Source Sans 3 carries the working voice across display, body, labels, button text, navigation, captions, and live-data indicator labels.
Editorial italic · Source Serif 4 Italic · hero only · once per page
The editorial moment.
Source Serif 4 Italic appears exactly once per page, in the hero headline. It is the parent's voice carried into Recipe B. The rarity is what makes it the editorial moment; using it twice would make it a heading style. Not in section headers. Not in CTAs. Not in cards. Not in the hero subhead.
Code + taxonomy IDs · Source Code Pro · code blocks, schema identifiers, taxonomy codes only
const dtpr = require('@dtpr/schema');
export const schema = dtpr.load('AI@2026-05-06-BETA');
Source Code Pro is reserved for code blocks, schema identifiers, and taxonomy codes — anywhere the technical content is literal code or a literal ID. Not in navigation. Not in button text. Not in section headers. Not in body prose. Source Sans 3 owns all UI.

Two rules

The italic cadence rule

Source Serif 4 Italic appears exactly once per page, in the hero headline. The rarity is the editorial moment. Using it twice would make it a heading style — and the parent's voice would lose its signal strength.

The mono rule

Source Code Pro is reserved for code, schema identifiers, and taxonomy codes. Not in navigation. Not in button text. Not in section headers. Not in body prose. Not in labels. Source Sans 3 owns all UI; the mono is the technical-content type.
