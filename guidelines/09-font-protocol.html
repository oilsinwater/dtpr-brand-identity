09 · Font Protocol

Where each family has jurisdiction

Three families, one job each — but the job extends across every surface a page carries. The font protocol is the rule book for the type system: every visual decision that involves type is tested against it. It is the page most often violated; treat it as the test for the type system.

MEMO

Public Sans — the working voice

Public Sans owns display, body, section titles, labels, button text, navigation, captions, and live-data indicator labels. If it is not editorial italic and it is not code, it is Public Sans.

Source Serif 4 Italic — the editorial moment

Source Serif 4 Italic appears exactly once per page, in the hero headline. This is the cadence rule — the italic carries the editorial voice, and the page is louder if it appears more than once.

Where each family may and may not appear

The font protocol is the rule book — every visual decision that involves type is tested against it. A second serif would split the voice.

Source Code Pro — code and taxonomy only

Source Code Pro is reserved for code blocks, schema identifiers, taxonomy codes, and live telemetry badges. Anywhere else, use Public Sans.

Avoid · Source Code Pro as a section header, label, or button text

SOURCE CODE PRO — CODE AND TAXONOMY ONLY

A taxonomy label, a section header, or a button — these are UI surfaces and Public Sans owns them. Mono is for code, not chrome.

Cross-surface rules

Apply across every surface
  • The italic moment is the hero's privilege. If a page already has Source Serif 4 Italic in the h1, no other surface gets italic — not section titles, not card titles, not blockquotes.
  • When in doubt, default to Public Sans. It's the workhorse. The italic exception and the code exception are the only roles that need a decision.
  • The chartreuse accents on live badges, telemetry pills, and the single primary CTA carry the visual signal — they don't compete with type.
  • Every surface follows the same hierarchy: Public Sans for structure, Source Serif 4 Italic for the editorial moment, Source Code Pro for code and taxonomy only.
Never
  • Never set Source Serif 4 Roman (non-italic) anywhere on the system.
  • Never combine Source Serif 4 with another serif. There is no second serif.
  • Never use Source Code Pro in chrome (nav, button, section header, caption, body).
  • Never italicize Public Sans body copy outside semantic <em> tags.
  • Never set the editorial italic below 36px — below that size, the italic loses its character.
