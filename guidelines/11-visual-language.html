    What makes the language work

    The Recipe B visual language works because of restraint. The chartreuse reservation rule means chartreuse never decorates — it only acts. The italic cadence rule means the serif never headlines — it only editorializes. The mono rule means the technical content type never invades the UI. When these rules hold, the identity reads as a tool, not a brochure.

    When the rules break — chartreuse on a hover state, italic in a section header, mono in a button label — the identity collapses toward "generic developer landing page." The brand book exists to keep the rules.
