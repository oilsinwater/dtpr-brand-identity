07 · Color Guide

The Recipe B palette

The DTPR Recipe B palette is built on high contrast — deep navy for structure, bright chartreuse reserved for interaction and status indicators. The palette is one of three DTPR recipe palettes; this page documents the Recipe B (Maker) variant. Recipe A and Recipe C have their own palettes and constraints — see the recipe handoff archives.

OBSERVED MEMO

The chartreuse reservation rule

Chartreuse is reserved for the live-data status indicator and the primary CTA. Period.

Chartreuse #9ACD00 is strictly reserved for the live-data status indicator and the primary CTA. It must NEVER be used on hero headlines, body text, decorative elements, hover states of non-primary elements, or background fills other than the CTA itself. Hover and active states of the chartreuse CTA use #B5DB1A (chartreuse-hover) and #84B400 (chartreuse-active).

This is the parent's "one accent, one job" principle, made literal. The rarity of chartreuse is what makes it trustworthy as an action signal. If chartreuse appears on hover, on labels, on borders, the rule has been violated.

Primary

#1B2B80
Navy Primary container borders, navigation headers, structural divides.
Hover: #2563D0
#2563D0
Medium Blue Hover states for primary actions, text link hovers, mid-level category tags. Not a primary CTA color.

Tertiary

#E8EAF5
Cool Paper Sidebar fills, table headers, desaturated container backgrounds.

Neutrals

#0F172A
Deep Slate Primary text ink. 16.4:1 contrast against paper.
#475569
Muted Slate Auxiliary text, placeholders, descriptions.
#F8F8F2
Blueprint Paper Default page background. Subtle warmth, draft-paper feel.
#F4F2EC
Warm Paper Card and container surfaces. Same family as paper, slight lift.
#E2E0D8
Border Grey All 1px structural borders on paper surfaces. Not for emphasis.
#0A0E1A
Terminal Dark Dark code surfaces and terminal outputs. Paired with #F8F8F2 text.

Reserved accent — chartreuse

#9ACD00
Chartreuse Reserved. Live-data indicator + primary CTA only. Hover: #B5DB1A. Active: #84B400.

Semantic status (system-wide)

Identical across Recipe B and the optional A-flavored and C-flavored registers — these are status colors, not brand colors.

#15803D
Positive Success states, "deployed," "verified."
#C2410C
Caution Warnings, deprecated-but-functional, soft alerts.
#B91C1C
Error Failures, broken states, hard alerts.
#1E40AF
Info Neutral informational badges.

Contrast ratios (verified)

Foreground / Background Ratio WCAG
Deep Slate #0F172A on Paper #F8F8F216.75:1AAA
Muted Slate #475569 on Paper #F8F8F27.11:1AAA
Inverse #F8F8F2 on Terminal Dark #0A0E1A18.06:1AAA
Deep Slate #0F172A on Chartreuse #9ACD009.44:1AAA (primary CTA)

Verify before shipping. All Recipe B contrast ratios must be checked against the canonical content using a current contrast tool. WCAG 2.2 AA is the floor; AAA where achievable.
