    Interactive Digital Presence

    The production implementation of Recipe B (Maker register). This interactive prototype consolidates DTPR's digital footprint into a responsive web application featuring dynamic WebGL city layer exploration, real-time telemetry, a lived civic journey simulator, and unified taxonomy navigation.

    VERIFIED PROTOTYPE RECIPE B NUXT 3 / WEBGL

    Live Prototype Viewport

    The web application runs below in an isolated sandbox environment, ensuring complete style and component independence from the parent brand guidelines document. You can interact directly with the 3D models, data chain explorer, and interactive simulator, or open the application in a dedicated window.

    RECIPE B PROTOTYPE // v2.1 (MAKER)
    Open Standalone App ↗

    Architectural Implementation of Brand Rules

    RULE 01 // PALETTE DISCIPLINE

    Reserved Chartreuse Action

    Chartreuse (#9ACD00) is strictly reserved for live state beacons, telemetry indicators, and primary CTAs. Base surfaces use Brand Navy (#1B2B80), warm paper (#F4F2EC), and frosted glass.

    RULE 02 // TYPOGRAPHIC TRIAD

    Three Faces, Clear Roles

    Source Serif 4 italic reserved for hero statements; Public Sans for UI headings and body copy; Source Code Pro monospace for terminal badges, schema keys, and telemetry metrics.

    RULE 03 // 3D EXPLODED LAYERS

    Urban Legibility Canvas

    Three.js WebGL model demonstrating how DTPR's digital accountability layer integrates seamlessly with physical buildings, transit networks, and public realm infrastructure.

    RULE 04 // DATA CHAINS

    Verifiable Accountability

    Two-column technical explorer mapping physical sensing nodes to responsible entities, municipal governance policies, and open machine-readable schemas.
