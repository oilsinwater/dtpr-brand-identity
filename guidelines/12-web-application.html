12 · Web Application

Interactive Digital Presence

The production implementation of Recipe B (Maker register). This interactive prototype consolidates DTPR's digital footprint into a responsive web application featuring a flat triangulated world map, a light-mode journey phone simulator, and unified taxonomy navigation — pared-back edition.

VERIFIED PROTOTYPE · V3 RECIPE B NUXT 4 / STATIC NO WEBGL

What changed V2 → V3

  • Removed WebGL shader auras and the orbital globe; replaced with static SVG triangulated mesh map.
  • JourneySection phone inverted from dark terminal substrate to warm-paper light mode.
  • Removed three.js dependency, gsap, maplibre-gl, @nuxt/content; build is now plain Nuxt 4 + @nuxt/ui.
  • CTA hierarchy corrected: chartreuse reserved for primary CTA only; secondary actions use blue #2563D0.
  • Home section spine matches V2's five-section structure (Hero / Problem / Standard / Day / Footprint) without the shader fixtures.

Live Prototype Viewport

The web application runs below in an isolated sandbox environment, ensuring complete style and component independence from the parent brand guidelines document. You can interact directly with the triangulated mesh map, the journey stepper, and the taxonomy/data-chain explorers, or open the application in a dedicated window.

Architectural Implementation of Visual Identity Rules

RULE 01 // PALETTE DISCIPLINE

Reserved Chartreuse Action

Chartreuse (#9ACD00) is strictly reserved for live state beacons, telemetry indicators, and the primary CTA. Base surfaces use Brand Navy (#1B2B80), warm paper (#F4F2EC), and frosted glass. Blue (#2563D0) is the secondary action color.

RULE 02 // TYPOGRAPHIC TRIAD

Three Faces, Clear Roles

Source Serif 4 italic reserved for hero statements; Public Sans for UI headings and body copy; Source Code Pro monospace for terminal badges, schema keys, and telemetry metrics.

RULE 03 // FLAT TRIANGULATED MAP

Static SVG World Map

Six continent meshes (NA, SA, EU, AF, AS, OC) triangulated via ear-clipping on hand-authored outlines, rendered as white-fill silhouette + white outline polyline + white wireframe triangles. Chartreuse pins for deployments, hollow chartreuse for pilots. No WebGL.

RULE 04 // LIGHT-MODE JOURNEY

Inverted Phone Substrate

JourneySection phone shifted from dark terminal substrate (V2) to warm-paper light mode (V3). Bezel white, screen #F4F2EC, chrome bars paper-tone. Chartreuse reserved inside the phone for the live status dot, "DTPR LABEL" caption, and the pinned action CTA.

RULE 05 // DATA CHAINS

Verifiable Accountability

Compact two-column explorer mapping physical sensing nodes to responsible entities, municipal governance policies, and open machine-readable schemas — no flip-card flourish, no flip animation.

RULE 06 // SECTION SPINE

Five-section structure, no shader fixtures

Home is Hero → Problem → Standard (5-icon row, taxonomy, data chain) → A Day With DTPR (light phone) → Global Footprint (flat map + city grid). No full-bleed dark band, no shader smoke fields, no orbital globe. Page reads on warm paper throughout.
